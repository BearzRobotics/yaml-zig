# yaml-zig

A YAML reader for Zig, built on `std.Io`. Its job is import: reading Solus `package.yml` recipes so `dkbuilder` can convert them to its TOML recipe format. It does not need to write YAML.

Status: not started. There is no code or specification yet; see `ai/AGENTS.md` for the engineering standards this project follows (including the `std.Io` requirement).
